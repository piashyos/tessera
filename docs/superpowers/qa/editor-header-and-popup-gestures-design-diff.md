**Итог.**
- Раскладка шапки совпадает с макетом и спекой: центр, ширина, обрезка с начала, кнопки, меню по ролям. При ×1,3 ничего не налезает.
- Начертание после решения оркестратора приведено к макету: путь — `labelLarge` (W500 13/18, 0sp), дата — `bodySmall` (W400 11/15, 0sp). Совпадает с `.title` / `.subtitle` (`--body-small`), проверено на 1.0 и ×1,3.

Снимки меню по ролям сняты в тестовом хосте (`ComponentActivity`): у него нет фона приложения, поэтому в «dark» тёмное только само меню, фон экрана светлый.

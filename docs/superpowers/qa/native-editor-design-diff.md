# Нативный редактор — сверка с макетом (QA Chunk 6b, п.3)

Устройство `emulator-5554` (AVD `Pixel_9_Pro`, API 36) при паритете с кадром макета: `wm size 1125x2436`, `wm density 480`
(375×812 CSS-пикселей × 3), язык приложения русский, палитра «Тёплая», динамические цвета выключены, HEAD 06a6fad.
Склейки «макет | приложение» — `.claude/local/native-editor-ref/qa/stitch-01…04.png`; снимки — `qa/shots/`; геометрия блоков
в dp — `qa/geometry-fs1.0.log`, `qa/geometry-fs1.3.log`. Значения макета — `design/mockups/shared.css` и `tokens.css`.

Кадры: 01 `editor-content-light`, 02 `editor-content-dark` — заметка «Q3 roadmap — приоритеты» с тем же текстом, тегами
`#срочно` `#встреча`, папкой «Работа › Проекты», закреплена; 03 `editor-empty` — новая заметка с кнопки «+», клавиатура;
04 `editor-format-bar` — «Идеи для редизайна», каретка в конце, клавиатура и панель.

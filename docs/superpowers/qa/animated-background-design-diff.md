# Живой фон — сверка с дизайном (Chunk 4)

**Макета нет.** В `design/mockups` фон не нарисован, строк зерна и градиента в `settings-*.html` нет (план §1). Все состояния — «без макета»: сверка со спекой `2026-11-13-animated-background-design.md` §1, §3, §4, §6 и с решениями пользователя.

**Устройство.** `emulator-5556`, 720×1280, 320 dpi, рендер SwiftShader. Код — с «импульсом» на нажатие (13:56).

**Скрины** — `.claude/local/animated-background-ref/qa/`:
- `shots/` — состояния;
- `pulse/` — серии кадров после тапа;
- `test/` — кадры `BackgroundGradientTest`;
- склейки: `sheet-lists.png`, `sheet-editors.png`, `sheet-variants.png`, `sheet-settings.png`, `sheet-tap-card.png`.

**Как измерено.** Пиксели скрина, разница по каналам в уровнях 0–255. Инструменты — `runs/cmp.py`. `runs/ampdiff.py` строит карту разницы, усиленную ×N: так видно, *где* фон меняется, даже когда глазом разницы нет.

## Движение — числа

Полоса пустого списка — `Rect(32, 200 – 688, 614–631)`, около 280 тыс. px. Сравнение с кадром покоя до касания.

**Перетаскивание.** Пятна у предела 0.09 × 720 = 65 px:
- light — 89.7 % полосы, максимум 2 уровня;
- dark — 92.7 %, максимум 2.

**Тап (импульс)** — первая серия r7, хост не перегружен:

| мс после нажатия | light: доля полосы, макс. шаг | dark |
| --- | --- | --- |
| ~100 | 0 % | 0 % |
| ~200 | 48.3 %, 3 | 20.6 %, 3 |
| ~350 | 70.0 %, 3 | 73.4 %, 4 |
| ~500 | 71.6 %, 3 | 77.2 %, 4 |
| ~800 | 37.6 %, 3 | 42.6 %, 3 |
| ~1200 | 12.3 %, 3 | 12.9 %, 3 |
| ~1800 | 1.2 %, 2 | 1.4 %, 2 |
| ~2500 | 0 | 0 |

- Первые ~100 мс фон стоит: кадр с началом импульса ещё не отрисован.
- Повтор серии в r8 пришёлся на перегруженный хост (load average до 31, эмулятор пропускал до 334 кадров). Тёмная серия там снята с опозданием на секунды, в таблицу не взята.

**Тап по карточке.** Полоса — нижняя часть экрана `Rect(32, 704 – 688, 1088)`, сравнение с редактором в покое через 3 с:
- на 836 мс фон сдвинут на 85.4 % полосы, максимум 4 уровня — импульс ещё идёт;
- на 49–403 мс разница — это сам список (карточки), не фон.

**Почему так мало.** Статичный тинт пятна сам по себе — 10–13 уровней на всю его площадь. Сдвиг на 39–65 px при радиусе 500–600 px меняет каждую точку лишь на долю этого тинта, отсюда 2–4 уровня. Движение плавного размытого пятна на 1–1.5 % яркости глаз не замечает. Сравнение кадров пика и покоя рядом (`pulse/ab-tap-empty-light-500ms.png` и `…-rest.png`) это подтверждает.

## Предложение по константам

Цель «заметно, но мягко»: пик движения около 8–12 уровней, то есть порядка самого тинта. Сейчас 2–4. Оценки ниже — линейная экстраполяция: изменение ∝ альфа × сдвиг / радиус. На коде не проверены, прод-код я не правлю.

**Вариант A — только движение, тинт остаётся «едва заметным» по спеке (рекомендую):**

| Константа | Сейчас | Предлагаю | Эффект (оценка) |
| --- | --- | --- | --- |
| `BackdropLimitFraction` | 0.09 (65 px) | 0.2 (144 px) | перетаскивание ×2.2 → ~4–5 уровней |
| `PulseAmplitude` A / B / C | 0.6 / 0.45 / 0.3 | 1.0 / 0.8 / 0.6 | от нового предела: A 144 px вместо 39 |
| `PulseScale` | 1.15 | 1.3 | вместе с амплитудой пик импульса ×3 → ~10 уровней |
| жёсткость спада импульса | 40 (~1.3 с спада) | 20 (~1.8 с) | при тапе по заметке импульс ещё виден, когда редактор уже на экране (~0.8 с) |

**Вариант B — если и после A движение не читается:** альфы пятен light 0.35 → 0.5, dark 0.25 → 0.35. Тинт вырастет примерно до 15–18 уровней — уже «цветной фон без сравнения», это расходится с критерием спеки §3, решение пользователя.

Альфы 0.35 / 0.25 для *статичного* вида менять не нужно: критерий спеки выполнен во всех шести палитро-темах.

**Как перепроверить.** После правки констант:
- `BackgroundGradientShotsTest#aTapOnTheEmptyListPulses` — пишет уровни по кадрам в logcat (`-s TagFolderAppearance`);
- `BackgroundGradientTest` — инварианты: при большем сдвиге «через 2.5 с — покой» тоже должно держаться, для предела 144 px это стоит проверить в первую очередь;
- кадры серии — глазом рядом с покоем.

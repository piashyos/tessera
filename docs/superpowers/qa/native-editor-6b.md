## Смерть процесса (adb e2e, `.claude/local/native-editor-ref/qa/am-kill-e2e.sh`)

APK от 02:02. Ввод — `adb shell input text` в открытую заметку; смерть — SIGKILL процесса (`run-as … kill -9`; `am kill`
процесс в фоне не убивал — pid оставался). Один прогон на путь.

| Случай | Нативный | Aztec (флаг выкл.) |
| --- | --- | --- |
| ввод, 3 с, Home, kill | сохранено | сохранено |
| ввод → Home → kill сразу (< 0,3 с) | **хвост потерян**: из «BBB» в базе «B» | потеряно «BBB» целиком |
| ввод → Home → 1 с → kill | сохранено | сохранено |

| ввод → 2 с → kill на переднем плане | сохранено | сохранено |

Вывод: окно потери ≈ 300 мс выдачи + 500 мс автосейва у обоих движков; на уход в фон экран не сбрасывает
отложенную правку редактора (нет flush на `ON_STOP`). Не регрессия нового редактора — общее поведение экрана.

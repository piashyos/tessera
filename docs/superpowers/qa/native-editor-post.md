(не закоммичены): `NativeEditorPerfTest` (замер команд в середине), `GlassBarShotsTest#caretStaysAboveTheGlassBar`.
Логи и скрины — `.claude/local/native-editor-ref/qa/post/`.
Прод-код всех прогонов — чистый `644b0f7`: APK собран в 11:20, перф 11:21, каретка 11:26, ручной проход 11:30–11:40 на том же APK.
Незакоммиченные правки другой сессии в этом worktree (`TesseraPopup`, `TesseraBottomActionBar`, `Color`, `NoteEditorScreen`,
`TesseraEditText`, 11:35–11:36) в них не входят.

не гоняли). Цена растёт с длиной хвоста: `relayout(from, t.length)`. Обычная буква через `command()` не идёт — клавиша внутри серии не изменилась.
Тест только пишет числа в лог, порога на команды не ставит (решение за руководителем).

## 3. Панель форматирования-стекло

`GlassBarShotsTest#caretStaysAboveTheGlassBar` — зелёный, лог `qa/post/caret-run1.log`. Заметка 80 абзацев; клавиши — настоящий Gboard
(Enter — его клавиша, Backspace — «Delete»), тап — `input tap`. Проверка на экране: низ каретки ≤ верх панели/клавиатуры (что выше).

- Набор в конце, 5 × Enter, «ab», 8 × Backspace (буквы, 5 слияний пустых абзацев, буква последней строки): низ каретки 522 px, верх
  панели 554 px — на каждом шаге.
- Тап по строке, которую край панели режет пополам (клавиатура открыта, строка 532..576, край панели 554, текст под панелью виден
  размытым, тап в видимую половину y = 543) → каретка 7236 в строке 7233..7261, заметка прокрутилась, низ каретки 492 (`glass-tap-*-keyboard-shown`).
- Без фокуса панели нет, поэтому «строки под панелью» там не бывает; что видно в этом случае — Н1.
- Скрины `glass-tap-{before,after}-keyboard-{hidden,shown}.png`, `glass-caret-after-{enter,backspace}.png`.

## Не проверено

- A/B перфа на `0680fd5^` — доля `repaintBelow` оценена вычитанием отдельным замером переразметки хвоста.
- Попап переименования папки (П1, недостижим); подпапка, теги, период в поиске — не открывались.
- Каретка над панелью — только light, только Gboard, `font_scale` 1.0.
- По ходу ручного прохода системный Back дважды вывел из приложения, `input text` ушёл в лаунчер (открылся Календарь и экран входа Google,
  ничего не подтверждено); всё закрыто, ниже — состояние устройства.

## 2. Настройки

### 2.1 Основной экран

Группа «Внешний вид» (`AppearanceSection`) заменяется группой «Общие» из двух строк:
- «Оформление» (`Icons.Rounded.Palette`, шеврон) → экран «Оформление» (§2.2), колбэк `onOpenAppearance`;
- «Язык» — как сейчас (значение + шеврон → шторка языка).

Остальные группы — без изменений, кроме строки лицензий (§4). Ключ `settings_section_appearance` больше не нужен — удалить
из обоих `strings.xml`.

### 2.2 Экран «Оформление»

- Маршрут `settings/appearance` в `NotesNavGraph`. Переходы — переходы NavHost по умолчанию, как у `SettingsRoute`
  (там `CompositionLocalProvider(LocalAnimatedVisibilityScope provides this)`, без `ScreenMotionWrapper`).
- ViewModel — **тот же экземпляр** `SettingsViewModel`, что у экрана настроек:
  `hiltViewModel(remember(entry) { navController.getBackStackEntry(SettingsRoute) })`. Новый экземпляр со своим
  `initialValue = SettingsState()` дал бы мелькание строк при переходе.
- Верхняя панель — как у экрана настроек: стрелка назад, крупный заголовок «Оформление».
- Строки (одна `SettingsGroup`, разделители `SettingsDivider` — как сейчас):
  1. «Тема» (`Icons.Rounded.Contrast` — не `Palette`, чтобы не повторять иконку строки «Оформление») — значение + шеврон →
     та же шторка темы, что сейчас;
  2. «Градиент фона» — Switch (как сейчас);
  3. «Анимация фона» — Switch, **только при включённом градиенте**; подзаголовок «Фон отзывается на касания»;
  4. «Зернистость» — Switch (как сейчас);
  5. «Интенсивность» и «Размер зерна» — ползунки, только при включённом зерне (как сейчас).
- Код строк переезжает из `SettingsScreen.AppearanceSection` в новый файл `ui/settings/AppearanceScreen.kt`
  (`GrainIntensityRow` — туда же, без копий). Теги для тестов в `UiTestTags`: корень экрана, «назад», строки-переключатели.

### 2.3 Настройка «Анимация фона»

- `UserPreferences`: `backgroundMotionEnabled: Flow<Boolean>`, `cachedBackgroundMotionEnabled`,
  `setBackgroundMotionEnabled(Boolean)`; DataStore-ключ `background_motion_enabled`, по умолчанию `true`.
  Все три fake (`test/fakes`, приватные в `SettingsViewModelTest` и `NotesListViewModelTest`).
- `SettingsState.backgroundMotionEnabled`, `SettingsViewModel.setBackgroundMotionEnabled`. Внешний `combine` в
  `themePrefs` уже на 5 аргументах: градиент и анимацию объединить в пару одним `combine`, как сделано для других.

  При `motionEnabled = false` градиент рисуется, слушателя касаний нет — фон стоит.

## 3. Анимация фона (переделка `core/ui/theme/BackdropMotion.kt`, `GrainOverlay.kt`)

### 3.1 Классификация жеста в слушателе (порядок проверок)

1. Отмена (`changedToUpIgnoreConsumed() && isConsumed`, в т. ч. при снятии узла) → возврат в покой без инерции и без
   «дыхания».
2. Мультитач: если за жест был прижат второй палец — это не тап.
3. Отпускание последнего пальца:
   - сдвиг за жест ≤ `touchSlop` **и** длительность ≤ `longPressTimeoutMillis` **и** один палец → **тап** → «дыхание»
     (§3.2) и возврат пятен в покой (они не двигались);
   - сдвиг ≤ `touchSlop`, но дольше `longPressTimeoutMillis` (долгое нажатие) → ни дыхания, ни инерции;
   - иначе → **взмах** → инерция (§3.3).

### 3.2 Тап → приглушённое «дыхание»

- `pulse` 0 → 1 → 0 без толчка от пальца, тише:
  - масштаб на пике `PulseScale` 1.3 → **1.12**;
  - свечение `PulseGlow` 2 → **1.25** (в покое тинт прежний — кисть строится с альфой `blobAlpha × PulseGlow`, рисуется
    `pulseGlowAlpha(pulse)`); на устройстве при 1.35 пик был 7–8 уровней, при 1.25 — 6 (замер 2026-11-13);
  - подъём `spring(1f, StiffnessMediumLow)`, спад `spring(0.8f, 20f, threshold 0.02)` — как сейчас.
- Тап по заметке: экран сменяется сразу, «дыхание» доигрывает за редактором — принято.
- Удалить мёртвый код толчка: `pulsePush`, `PulseAmplitude`, `pulseOrigin`, `blobShift` и их тесты.

### 3.3 Скролл и свайп → цвета расходятся, по инерции

- Нажатие (первый `down`) **ловит** пятна: `stop()` текущих анимаций сдвига, `target` = текущее значение — без скачка, тап
  во время инерции её останавливает.
- Пока палец ведёт: «сырой» сдвиг каждого пятна накапливается как смещение жеста, **повёрнутое на свой угол** (A 0°,
  B +120°, C −120°) и умноженное на коэффициент `BackdropGains` **0.2 / 0.15 / 0.1** (было 0.35 / 0.25 / 0.15). Видимый
  сдвиг — мягкое насыщение: `limit × tanh(|raw| / limit)` по длине вектора, направление сохраняется. Предел
  `BackdropLimitFraction` 0.2 → **0.12**. Так обычный скролл не упирает пятна в предел — остаётся место для инерции.
- Скорость: в слушателе `VelocityTracker`, в него кладётся **накопленная позиция из средних сдвигов**
  (`addPosition(uptime, accumulated)`), `resetTracking()` на каждый новый жест; скорость ограничена
  `viewConfiguration.maximumFlingVelocity`.
- Отпускание (взмах): начальная скорость пятна = скорость жеста, повёрнутая и умноженная так же. Инерция —
  `Animatable.animateDecay(v, exponentialDecay(frictionMultiplier = 1.6f, absVelocityThreshold = 2f))`.
  Ограничение кругом: конечная точка экспоненциального декея линейна по скорости, траектория — прямая. Перед запуском
  `calculateTargetValue(...)`; если конечная точка за пределом `limit`, скорость уменьшается пропорционально, чтобы
  конечная точка легла на окружность. `updateBounds` не используется (он квадратный и обрывает декей по обеим осям).
- После инерции — возврат в покой: `spring(dampingRatio = 1f, stiffness = 12f, visibilityThreshold =
  Offset.VisibilityThreshold)`, без перелёта.
- Окно «до покоя» (для тестов) — считать из констант; ориентир: инерция ≤ ~1 с + возврат ~2.3 с.

### 3.4 Общее

- «Удалить анимации» (`MotionDurationScale` 0) — ни дыхания, ни сдвигов (как сейчас).
- `motionEnabled = false` — слушателя нет.
- В покое кадров нет; всё читается в draw-фазе слоя пятен (как сейчас).
- Константы подбираются на устройстве «заметно, но не бросается в глаза», итог — в план. Ориентир по прошлым замерам:
  дыхание ~4–6 уровней цвета на пике (было 9), сдвиг от скролла ~2–4 уровня.

  назад; исправить можно только темой в манифесте (отдельный апрув). 17.4.0+ тянет Compose adaptive / navigation3,

- Вместо неё — **свой экран в стиле приложения на данных плагина** (без новых зависимостей и правок манифеста):
  - чтение `R.raw.third_party_license_metadata` (строки `offset:length name`) и `R.raw.third_party_licenses` (тексты по

    шторка или экран с текстом лицензии (моноширинно не нужно, `bodySmall`, выделяемый текст);
  - строка «Лицензии открытого ПО» в «О приложении» открывает этот маршрут.
- В debug-сборке список из одной записи «Debug License Info» — так задумано плагином.

## 6. Баг: боковое меню теряет выбранный раздел

- Причина: `NotesListScreen.kt:183` — `var selectedSystemKey by remember { mutableStateOf("all") }`. Переход в настройки
  убирает экран списка из композиции; «Назад» создаёт его заново — `remember` снова `"all"`. `NotesListViewModel` живёт в
  записи стека навигации и показывает корзину (`state.isTrashView`), меню — «Все заметки». Два источника правды.
- Исправление в корне: выбранный пункт выводится из состояния ViewModel, локальной копии нет:
  `isTrashView → "trash"`, `isArchiveView → "archive"`, `isPinnedView → "pinned"`, `isSharedView → "shared"`, иначе
  `"all"` (при `selectedFolderId != null` подсвечивается папка — как сейчас; `selectFolder` / `showAllNotes` в VM уже
  сбрасывают системные разделы). `onSystemSelect` / `onFolderSelect` больше не пишут локальное состояние.

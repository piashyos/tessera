## 2. Решения

- **E1. Таблицы — вариант A (оверлей), с условием** (решение руководителя 2026-11-07 по спайку P2-0).
  - Замеры на emulator-5556, живой Gboard:
    - IME в ячейке: набор, Backspace, Enter, автокоррекция — ✓;
    - отставание оверлея при скролле: 0 из 35 кадров (PixelCopy);
    - синхронизация высоты: тот же проход pre-draw;
    - тап по ячейке не ставит каретку;
    - ячейка у нижнего края поднимается над IME только с обвязкой (~25 строк: `requestChildRectangleOnScreen`
      + выделение на абзац таблицы).
  - Почему A: правка в тексте, как в Apple Notes. В B широкие таблицы обрезаются, а правка только в листе.
  - **Условие.** Вертикальный свайп, начатый на таблице, сейчас не скроллит документ: оверлей забирает жест.
    Первый шаг P2-2 — перехват вертикального drag в родителе, проверка на устройстве. Если за разумное время
    не решается — откат на B: в прототипе есть `SpikeGridDrawer` и лист.
  - Ещё для P2-2:
    - Enter в ячейке даёт `\n`, а GFM превращает его в пробел, и данные меняются. Решение: Enter = следующая
      ячейка;
    - тап в отступ спана ставит каретку в абзац таблицы;
    - выделение и ручки EditText прячутся под оверлеем.
  - Прототип (не в git): `.claude/local/native-editor-ref/p2/spike-src/` — `SpikeTableHost.kt`
    (позиционирование A1, syncHeight, обвязка IME), `SpikeGboard.kt` (основа instrumented P2-2),
    `SpikeTableTest.kt` (замеры). Скрины — `.claude/local/native-editor-ref/p2/`.
- **E2. Слои картинок.** Чтение файлов, Room и Drive уезжают в `data/images` (новый класс рядом с
  `ImageDownloader`, наружу — `suspend fun decode(src, maxWidthPx)` (Loaded | Unavailable) и
  `prefetchSizes` + синхронный размер из кэша для плейсхолдера без прыжка, §3.1; без DAO в UI).
  `ImageRef`/`parseImageRef` — в `domain/model`. Адаптер
  `ObjectImageSource` с `LruCache` живёт в `ui/editor/components`. Интерфейс `ObjectImageSource` — в
  `ui/editor/engine`.
- **E3. «Тихая» перемера после загрузки** (§3.2) — отдельный путь движка без версии, истории и выдачи.
- **E4. Апрув Gradle — получен 2026-11-08**, ответ пользователя «Да, удаляй» в сессии руководителя. Gradle
  правит руководитель, отдельным последним коммитом, после проверки резолва.
- **E5. Коммиты** — как в этапе 1: оркестратор локально после приёмки среза, без push.

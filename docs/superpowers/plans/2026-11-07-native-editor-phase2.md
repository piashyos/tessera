> Ведёт оркестратор по скиллу `feature-team`. Спека: `docs/superpowers/specs/2026-11-07-native-editor-phase2-design.md`

**Цель:** картинки и таблицы в нативном редакторе, затем нативный редактор — единственный, Aztec удалён.

## 1. Источники и окружение

- Спека этапа 2: §2 — объекты, §3 — картинки, §4 — таблицы, §5 — удаление, §6 — срезы, §7 — тесты,
  §8 — приёмка.
- Ориентиры для картинок и таблиц из кода: `TesseraImageLoader`, `ImageSelectionOverlay`,
  `ImageSelectionGeometry`, `TableBlockEditor`, `TableActionsBar`, путь `EditorBody` в
  `NoteEditorScreen`, `RichNoteBody` — вставка картинок, IME, тап.
- Устройства:
  - `emulator-5554` — у пользователя для ручной проверки, команде его **не трогать**;
  - команда работает на втором эмуляторе (AVD `Small_Phone`, порт 5556 → `emulator-5556`);
  - инструментальные прогоны передают `ANDROID_SERIAL=emulator-5556`.
- База для сравнения прогонов — HEAD `dd6e2bc` (этап 1 + доводка).

## 2. Решения

- **E1. Таблицы — по итогам спайка P2-0** (§4). Решение и замеры вписываются сюда.
- **E2. Слои картинок.** Чтение файлов, Room и Drive уезжают в `data/images` (новый класс рядом с
  `ImageDownloader`, наружу — `suspend fun decode(src, maxWidthPx)` (Loaded | Unavailable) и
  `prefetchSizes` + синхронный размер из кэша для плейсхолдера без прыжка, §3.1; без DAO в UI).
  `ImageRef`/`parseImageRef` — в `domain/model`. Адаптер
  `ObjectImageSource` с `LruCache` живёт в `ui/editor/components`. Интерфейс `ObjectImageSource` — в
  `ui/editor/engine`.
- **E3. «Тихая» перемера после загрузки** (§3.2) — отдельный путь движка без версии, истории и выдачи.
- **E4. Апрув Gradle — ожидается.** P2-0…P2-3 идут сейчас; перед P2-4 — один вопрос пользователю (три файла Gradle + чек-лист релиза).
- **E5. Коммиты** — как в этапе 1: оркестратор локально после приёмки среза, без push.

## 3. Решения

- D1. Новая настройка `background_motion_enabled` (DataStore, по умолчанию `true`). Room / Firestore не меняются.
- D2. `GrainOverlay` — новый необязательный параметр `motionEnabled = true`.
- D3. Лицензии — плагин `oss-licenses-plugin` 0.13.0 (подключил оркестратор, апрув пользователя); библиотеку не берём,
  свой экран на `R.raw.third_party_license_metadata` / `R.raw.third_party_licenses` (оба есть в `R` — проверено).
- D4. Экран «Оформление» — маршрут `settings/appearance`, тот же экземпляр `SettingsViewModel` через запись `SettingsRoute`.
- D5. Баг меню — выбор выводится из `NotesListState` (спека §6).
- D6. Роли: `ui` (анимация, `core/ui/**`) и `feature` (всё остальное в `ui/**`, `MainActivity`, `res/**`, а также —
  назначено здесь — `core/preferences/**` и три fake `UserPreferences`: правка маленькая, отдельная роль `data` не нужна).
  Идут параллельно: файлы не пересекаются; `MainActivity` (передача `motionEnabled`) `feature` правит последней, когда
  параметр уже есть у `GrainOverlay`.
- D7. Устройство команды — `emulator-5556`; `emulator-5554` — пользовательский, не трогать.
- D8. Связь с ролями — файлами `.claude/local/msg-to-orchestrator-<роль>-<N>.md` + `--resume`.

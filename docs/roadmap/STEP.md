# Процедура одного шага (фазы)

Команда на каждый шаг:

> **«Сделай фазу N по STEP.md»**

Что я делаю по этой команде (без доп. указаний):

1. Беру фазу N из `ROADMAP-shared-notes.md` и нужные части спек.
2. Короткий план задач фазы → жду «ок» (или «го» — тогда сразу делаю).
3. Реализую: код + тесты (TDD, где есть логика).
4. Прогоняю тесты/сборку. Зелёные — иду дальше, красные — чиню.
5. Обновляю таблицу состояния в `ROADMAP-shared-notes.md` (статус ✅, коммит, дата).
6. Атомарный коммит.
7. Пишу 2–3 строки: что сделано, что проверено, что дальше.

Правила:
- Не перехожу к фазе N+1, пока N не ✅ и тесты не зелёные.
- Фаза 7 (CRDT-ядро) — гейт: без зелёных property-тестов фазы 8–9 не начинаю.
- Если по ходу всплывает развилка — спрашиваю одним вопросом, не угадываю.

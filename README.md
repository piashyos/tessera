# Tessera

A fast, local-first Android notes app (Room) with a modern Compose UI, optional cloud sync, and Google sign-in.

- **Package:** `app.tessera`
- **Build:** `./gradlew :app:assembleDebug`
- **Unit tests:** `./gradlew :app:testDebugUnitTest`
- **Instrumented tests:** `./gradlew :app:connectedDebugAndroidTest` (needs an emulator/device)

Implementation progress is tracked in [`docs/superpowers/PROGRESS.md`](docs/superpowers/PROGRESS.md), driven by the [plan](docs/superpowers/plans/2026-06-14-android-notes.md).

## Firebase / Google sign-in

Live Google sign-in is wired up via Credential Manager + Firebase Auth:

- `AuthRepositoryImpl` uses Credential Manager (`GetGoogleIdOption`) to obtain a Google ID token,
  exchanges it for a Firebase credential, and publishes `currentUser` from the Firebase auth state.
- `FirebaseModule` provides `FirebaseAuth` and `FirebaseFirestore`.
- `CurrentActivityHolder` (set from `MainActivity.onResume`) gives the repository the Activity that
  Credential Manager needs to present its UI, without leaking it into the ViewModel layer.
- The server client id comes from `R.string.default_web_client_id`, generated by the
  `google-services` plugin from `app/google-services.json`.

### Setup (for a fresh checkout)

`app/google-services.json` is **gitignored** — each developer supplies their own:

1. In the Firebase console, add an Android app with package `app.tessera`.
2. Enable **Google** as a sign-in provider under Authentication.
3. Download `google-services.json` into `app/`.
4. Build and run; tap the settings icon → **Sign in with Google**.

The current local config targets the Firebase project `notes-d3abc`.
